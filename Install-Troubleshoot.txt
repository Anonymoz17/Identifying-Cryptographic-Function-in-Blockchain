┌─ TROUBLESHOOTING ──────────────────────────────────────────────────────────┐
│                                                                             │
│  "Python not found"                                                        │
│    → Install Python 3.10-3.13 from python.org                              │
│    → Restart Command Prompt after install                                  │
│    → Verify: > python --version                                            │
│                                                                             │
│  "Installation failed"                                                     │
│    → Check internet connection                                             │
│    → Try again: > install.bat -Force                                       │
│    → Check if you have 2GB free disk space                                 │
│                                                                             │
│  "Can't run app"                                                           │
│    → Make sure install.bat completed successfully                          │
│    → Run run.bat from project root (not from subdirectories)               │
│    → Try: > install.bat -Force                                             │
│                                                                             │
│  For more help, see README.md or QUICKSTART.md                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ WHAT INSTALL.BAT DOES ────────────────────────────────────────────────────┐
│                                                                             │
│  ✅ Checks Python 3.10+ is installed                                       │
│  ✅ Creates virtual environment (.venv folder)                             │
│  ✅ Installs all Python packages (from requirements.txt)                   │
│  ✅ Verifies imports work correctly                                        │
│  ✅ Shows "Installation Complete!" when done                               │
│                                                                             │
│  Total Time: 2-5 minutes (first time)                                      │
│              ~10 seconds (if already installed)                            │
│                                                                             │
