┌─ TROUBLESHOOTING ──────────────────────────────────────────────────────────┐
│                                                                             │
│  "Python not found"                                                        │
│    → Install Python 3.10-3.13 from python.org                              │
│    → Restart PowerShell after install                                      │
│    → Verify: $ python --version                                            │
│                                                                             │
│  "Installation failed"                                                     │
│    → Check internet connection                                             │
│    → Try again: $ .\install.ps1 -Force                                     │
│    → Check if you have 2GB free disk space                                 │
│                                                                             │
│  "Can't run app"                                                           │
│    → Make sure install.ps1 completed successfully                          │
│    → Run .\run.ps1 from project root (not from subdirectories)             │
│    → Try: .\install.ps1 -Force                                             │
│                                                                             │
│  For more help, see README.md or QUICKSTART.md                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ REQUIREMENTS ─────────────────────────────────────────────────────────────┐
│                                                                             │
│  • Windows 10 or later                                                     │
│  • Python 3.10, 3.11, 3.12, or 3.13                                        │
│  • ~2 GB free disk space (for Ghidra)                                      │

│  • PowerShell (usually pre-installed on Windows)                           │

┌─ WHAT INSTALL.PS1 DOES ────────────────────────────────────────────────────┐
│                                                                             │
│  ✅ Checks Python version (3.10-3.13)                                      │
│  ✅ Creates virtual environment (.venv folder)                             │
│  ✅ Installs Python packages (from requirements.txt)                       │
│  ✅ Downloads Ghidra (if not already installed)                            │
