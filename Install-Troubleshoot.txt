┌─ COMMON COMMANDS ──────────────────────────────────────────────────────────┐
│                                                                             │
│  First-time setup (installs + launches):                                   │
│    > setup.bat                                                             │
│                                                                             │

┌─ TROUBLESHOOTING ──────────────────────────────────────────────────────────┐
│                                                                             │
│  "Python not found"                                                        │
│    → Install Python 3.10-3.13 from python.org                              │
│    → Restart Command Prompt after install                                  │
│    → Verify: > python --version                                            │
│                                                                             │
│  "Installation failed"                                                     │
│    → Check internet connection                                             │
│    → Try again: > install.bat -Force                                       │
│    → Check if you have 2GB free disk space                                 │
│                                                                             │
│  "Can't run app"                                                           │
│    → Make sure install.bat completed successfully                          │
│    → Run run.bat from project root (not from subdirectories)               │
│    → Try: > install.bat -Force                                             │
│                                                                             │
│  For more help, see README.md or QUICKSTART.md                             │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ REQUIREMENTS ─────────────────────────────────────────────────────────────┐
│                                                                             │
│  • Windows 10 or later                                                     │
│  • Python 3.10, 3.11, 3.12, or 3.13                                        │
│  • ~2 GB free disk space (for Ghidra)                                      │
│  • Internet connection (for downloads)                                     │
│  • Command Prompt or PowerShell (usually pre-installed on Windows)         │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ ADVANCED OPTIONS ─────────────────────────────────────────────────────────┐
│                                                                             │
│  Custom Ghidra version:                                                    │
│    > install.bat -GhidraVersion 10.0                                       │
│                                                                             │
│  Python only (no Ghidra):                                                  │
│    > install.bat -SkipGhidra                                               │
│                                                                             │
│  Force reinstall (removes .venv and starts over):                          │
│    > install.bat -Force                                                    │
│                                                                             │
│  Combine options:                                                          │
│    > install.bat -Force -SkipGhidra                                        │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

┌─ WHAT INSTALL.BAT DOES ────────────────────────────────────────────────────┐
│                                                                             │
│  ✅ Checks Python version (3.10-3.13)                                      │
│  ✅ Creates virtual environment (.venv folder)                             │
│  ✅ Installs Python packages (from requirements.txt)                       │
│  ✅ Downloads Ghidra (if not already installed)                            │
│  ✅ Verifies everything works                                              │
│  ✅ Shows "Installation Complete!" when done                               │
│                                                                             │
│  Total Time: 5-10 minutes (first time)                                     │
│              ~30 seconds (if already installed)                            │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘
