IF STATIC DETECTION HANGS AT ~58%:
──────────────────────────────────────────────────────────────────────────────

1. OPEN NEW TERMINAL AND MONITOR LOG:

   Mac/Linux:
   $ tail -f <your_case_workdir>/static_detection_debug.log

   Windows PowerShell:
   > Get-Content -Path "<your_case_workdir>/static_detection_debug.log" -Wait

2. WAIT FOR IT TO HANG (or complete)

3. FIND THE PROBLEM:

   Stuck file hash:
   $ grep "Starting analysis" <case>/static_detection_debug.log | tail -1
   Output: [150/1951] Starting analysis of abc123def456...

   Stuck stage:
   $ grep "\[STAGE" <case>/static_detection_debug.log | tail -1
   Output: [STAGE 2] Calling ensure_ghidra_export...

4. FIX BASED ON STAGE:

   IF [STAGE 1] stuck:
     → Try "quick" profile (faster, less analysis)
     → Check file size (if >50MB, may be slow)

   IF [STAGE 2] stuck:
     → Disable Ghidra: Edit config.py, set Ghidra policy to "never"
     → Ghidra can hang on complex binaries

   IF [STAGE 3] stuck:
     → Check which heuristics loaded
     → Try disabling problematic heuristic in runner.py

================================================================================

WHAT EACH STAGE DOES:
──────────────────────────────────────────────────────────────────────────────

[STAGE 1] Static Preprocessing
  ├─ Reads input.bin file
  ├─ Extracts strings
  ├─ Calculates constants
  ├─ Measures entropy
  └─ Expected time: 1-10 seconds

[STAGE 2] Ghidra Analysis (if enabled)
  ├─ Disassembles binary
  ├─ Extracts functions
  ├─ Builds call graphs
  └─ Expected time: 2-30 seconds (or SKIPPED)

[STAGE 3] Heuristics
  ├─ Signature matching
  ├─ Pattern detection
  ├─ Constants analysis
  └─ Expected time: 1-5 seconds

================================================================================

COMMON ISSUES AND FIXES:
──────────────────────────────────────────────────────────────────────────────

ISSUE: STAGE 1 hangs for >15 minutes
FIX:   Use "quick" profile instead of "full"
       (Skips expensive constant pattern detection)

ISSUE: STAGE 2 (Ghidra) hangs for >15 minutes
FIX:   Disable Ghidra entirely
       (Edit config.py, set policy = "never")

ISSUE: STAGE 3 (Heuristics) hangs for >15 minutes
FIX:   Disable heuristics one by one to find culprit
       (Comment out in runner.py lines 282-302)

ISSUE: Says analyzing file but log shows nothing new
FIX:   Log file may be buffering
       Try: ctrl+C and re-read log
       Or: Increase timeout (DEFAULT_PIPELINE_TIMEOUT in runner.py)
